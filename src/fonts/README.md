# Fonts

`barlow-condensed-500-latin.woff2` and `barlow-condensed-700-latin.woff2` are Barlow Condensed by Jeremy Tribby, the
latin subset as served by Google Fonts, licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Bundled here so the site makes no request to a font host.
`scripts/fetch_font.py` re-downloads them.
